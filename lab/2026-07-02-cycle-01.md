## What hypothesis was tested?

That the CCI layer (`studyplan/cci/`) contains discoverable architectural invariants that can be extracted by comparing multiple process implementations.

Specifically: ComputationProcess, ClassificationProcess, EvaluationProcess, and DiagnosticProcess should converge on a shared execution structure that is not coincidental but architecturally necessary.

## What evidence was gathered?

### M0 — Structural scan of CCI layer

Six duplicated patterns found across all four process implementations:

| # | Pattern | Implementations |
|---|---------|-----------------|
| 1 | `finished()` → `bool(state.get("done"))` | All 4 |
| 2 | `concept_id` property | All 4 |

| 4 | `step()` returns `{"next_state": ..., "transition": ...}` | All 4 |
| 5 | For-loop over `trace.events` in interpreters | All 10 interpreters |
| 6 | State skeleton `{inputs, done, result}` | All 4 |

### M2.5 v1 (methodological error) — Syntax falsification

Falsified the **syntax** of each pattern (e.g., "the key name must be `done`") instead of falsifying the **principle** (e.g., "the runtime requires a deterministic termination predicate").

Result: concluded "nothing promotes" — incorrect.

### M2.5 v2 (corrected) — Principle-level falsification

Re-interpreted all six patterns as principles at correct layers:

| # | Principle | Layer | Survives? |

## What surprised us?

1. **Syntax falsification is subtly wrong.** The v1 protocol defined falsification as "try to break the pattern with a counterexample." But patterns are syntax. Principles are architecture. Falsifying a pattern tells you nothing about whether the principle is valid. This was a methodological error that Protocol v2 corrected with Rule 4 ("Generalize Before Falsifying").

2. **The runtime enforces only one invariant** (`step_result["next_state"]`). Everything else is conventional. The architecture is much smaller than the code suggests.

3. **The same state skeleton appears in all four algebras** despite being independently implemented. `{inputs, done, result}` is a discovered convergence, not a designed standard.
